# Hero photographs and typography

User-provided Unsplash photographs, downloaded on 2026-11-15 and encoded locally as WebP (Sharp quality 85). Left-to-right order is retained; mobile follows the same order vertically. These decorative photographs are not asserted to depict the Iowa pilot. The prior generated image remains in the closing section.

“Futuru” was interpreted as Futura. This Mac has Futura installed. Home typography uses `Futura, "Century Gothic", var(--font-geist-sans), sans-serif`. No system font was copied or redistributed. Devices without Futura use a fallback until a licensed webfont is provided. Other app screens retain their existing typography.

## NASA insignia
