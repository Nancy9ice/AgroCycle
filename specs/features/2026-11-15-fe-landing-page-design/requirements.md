# Requirements: Landing-page design

## Covers
Supports NFR-02 (explainability), NFR-06 (maintainability) and NFR-08 (usability). This Phase 7 visual maintenance task does not complete the broader real-data profile exit check.

## Acceptance criteria
1. Hero has a locally served agricultural image with legible text and working field/demo CTAs.
2. Hero, decision, strategies, workflow, honesty, evidence and final CTA remain separate files; motion and icon code is shared.
3. Sections animate subtly once on viewport entry; reduced-motion users see static content. Content is available without JavaScript and with keyboard navigation.
4. Layouts at 360, 768 and 1440 px have no horizontal overflow; navigation and named controls remain usable.
5. Preserve strategy definitions, five-step journey, three possible outcomes, source evidence labels and spatial limitations, Iowa pilot scope and demo boundary disclosures. No fabricated impact or predictive claims.
6. Hero image is explicitly illustrative; asset provenance and generation prompt are recorded. Optimize it for web delivery.
7. Lint, typecheck, existing tests, changed-file formatting and production build pass. Record existing warnings and browser verification limitations.

8. Landing navigation shows at the top and on upward scroll, hides on downward scroll after the top area, stays legible over all sections, and remains accessible while focused or with its mobile menu open.

## Out of scope
Other application screens, backend/data changes, automatic scrolling, scroll hijacking and publishing.
